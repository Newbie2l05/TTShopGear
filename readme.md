# 📖 Giới thiệu website/hệ thống

**TTShopGear** là website thương mại điện tử chuyên cung cấp các thiết bị gaming và linh kiện máy tính cao cấp dành cho game thủ và người dùng công nghệ.

Hệ thống được xây dựng bằng **WordPress + WooCommerce** với giao diện hiện đại theo phong cách dark mode và glassmorphism. Website hỗ trợ quản lý sản phẩm, giỏ hàng, thanh toán trực tuyến và tối ưu trải nghiệm người dùng trên mọi thiết bị.

### 🎯 Mục tiêu dự án

- Xây dựng website bán hàng trực tuyến hoàn chỉnh
- Áp dụng kiến thức WordPress, WooCommerce và PHP vào thực tế
- Thiết kế giao diện responsive hiện đại
- Tích hợp thanh toán và quản lý đơn hàng
