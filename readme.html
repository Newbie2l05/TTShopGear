# TTShopGear Storefront WordPress + WooCommerce cho cửa hàng gear gaming, được tùy biến giao diện riêng theo phong cách landing page, đồng bộ toàn bộ trải nghiệm mua sắm bằng tiếng Việt. ## Demo tính năng - Giao diện storefront custom đồng bộ toàn site - Trang chủ dạng landing page - Danh mục, chi tiết sản phẩm, tìm kiếm, giỏ hàng, checkout, tài khoản - Live search gợi ý sản phẩm theo từ khóa - Thêm giỏ hàng bằng AJAX - Checkout tiếng Việt - Chọn tỉnh / thành phố và phường / xã theo dữ liệu Việt Nam - Thanh toán COD - Thanh toán QR động qua VietQR, MoMo quét được và tự điền số tiền đơn hàng - Giá hiển thị theo VND ## Stack - WordPress - WooCommerce - PHP - JavaScript - CSS custom ## Cấu trúc chính ```text wp-content/ └── themes/ └── ttshopgear-landing/ ├── assets/ │ ├── css/ │ ├── js/ │ └── data/ ├── inc/ ├── templates/ └── woocommerce/
